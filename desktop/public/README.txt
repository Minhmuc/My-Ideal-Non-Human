Hướng dẫn thêm ảnh nền cho MINH
=====================================

1. Đặt ảnh nền vào folder này (desktop/public/)
2. Đổi tên ảnh thành: background.jpg
   (hoặc background.png nếu dùng PNG)

3. Nếu dùng tên file khác, sửa trong: desktop/src/index.css
   Dòng: background-image: url('/background.jpg');
   
4. Khuyến nghị:
   - Kích thước: 1920x1080 trở lên
   - Định dạng: JPG (nhẹ) hoặc PNG (chất lượng cao)
   - Ảnh tối màu hoặc có độ tương phản thấp sẽ đẹp hơn

5. Chạy lại: npm run dev

Ví dụ:
  desktop/public/background.jpg  ← Đặt ảnh ở đây
